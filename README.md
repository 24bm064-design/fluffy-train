# fluffy-train


MATLAB Predictive Modeling of Hospital Resource Allocation

📌 Project Overview

This project presents a machine learning-based predictive model developed in MATLAB to forecast hospital resource requirements using historical healthcare data. The system helps in predicting future resource allocation such as beds, ICU capacity, or staff requirements based on patient load and other operational factors.

Efficient hospital resource planning is critical for managing patient care, reducing overcrowding, and improving healthcare service delivery. This project demonstrates how data-driven modeling can support intelligent decision-making in healthcare systems.

🎯 Objectives
1. Analyze historical hospital data
2. Develop a predictive regression model using MATLAB
3. Forecast future hospital resource requirements
4. Evaluate model performance using statistical metrics


🧠 Methodology

1. Data Preprocessing
  Removal of missing values
  Feature-target separation

2. Model Development
    Random Forest Regression (Ensemble Learning)
    80–20 Train-Test data split

3.Model Evaluation
    Mean Absolute Error (MAE)
    Root Mean Square Error (RMSE)
    R-squared (R²)

4. Future Prediction
    Predicts resource requirement under new hospital conditions


⚙️ Technologies Used
   1.  MATLAB
   2. Machine Learning Toolbox
   3. Random Forest (Ensemble Trees)


📊 Model Output
 The model:
 
   a. Predicts hospital resource demand
   
   b. Compares actual vs predicted values
   
   c. Provides performance metrics for accuracy validation
